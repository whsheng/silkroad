# 未来 2 到 4 周运营观察指标表

适用起始时间：

- 从 `2026-06-01` 开始观察

目的：

- 判断网站是否开始被搜索引擎收录
- 判断用户是否理解网站定位并产生有效访问
- 判断投稿链路是否稳定
- 判断哪些页面类型和内容主题先具备搜索增长潜力

说明：

- 前 2 到 4 周不追求绝对流量规模，重点看趋势、信号和异常
- 不建议过早大改站点结构，先让真实数据跑起来
- 每周输出一次简报即可，不需要每天重度分析

## 核心指标表

| 维度 | 指标 | 工具 | 频率 | 2 到 4 周内重点看什么 | 触发动作 |
|---|---|---|---|---|---|
| SEO | 已收录页面数 | Google Search Console | 每周 2 次 | 是否从 0 开始稳定增长 | 2 周后仍几乎不收录：检查 sitemap、canonical、内部链接 |
| SEO | 总曝光量 | Google Search Console | 每周 2 次 | 是否开始出现长尾曝光 | 曝光很低：继续补专题与分类页文案 |
| SEO | 总点击量 | Google Search Console | 每周 2 次 | 是否出现第一批自然点击 | 有曝光无点击：优先改标题和摘要 |
| SEO | 平均 CTR | Google Search Console | 每周 1 次 | 哪些页面有展示但 CTR 低 | CTR 明显低：微调 title / description |
| SEO | 重复页 / 抓取异常 | Google Search Console | 每周 1 次 | 是否还有主域重复、重定向、抓取异常 | 出现异常：先修技术问题，再继续发内容 |
| 流量 | Users / Sessions | GA4 | 每周 2 次 | 是否开始有自然访问和回访 | 几乎无访问：加外部发布、社媒分发、目录提交 |
| 流量 | Top landing pages | GA4 | 每周 1 次 | 哪些入口页先获得流量 | 把有势能的页继续做内容扩展 |
| 流量 | 提交页访问量 | GA4 | 每周 1 次 | 是否有人进入投稿页 | 访问高但无提交：检查表单文案和信任感 |
| 互动 | Engaged sessions / engagement rate | GA4 | 每周 1 次 | 用户是否愿意继续浏览 | 参与度低：强化首页信息表达和站内推荐 |
| 内容 | 8 篇专题的曝光与点击 | Search Console + GA4 | 每周 1 次 | 哪些标题先承接到搜索 | 曝光高点击低：改标题；点击有了就继续扩写 |
| 投稿 | 新投稿数量 | GitHub Issues | 每周 1 次 | 是否开始有真实站点投稿 | 有量说明闭环成立；无量先不急，配合站外引导 |
| 投稿 | 有效投稿率 | GitHub Issues | 每周 1 次 | 投稿里有多少值得收录 | 垃圾投稿多：继续强化 Turnstile 和表单限制 |
| 投稿 | 审核耗时 | GitHub Issues | 每周 1 次 | 从提交到处理是否过慢 | 超过 7 天：固定每周审核时段 |
| 系统 | `/api/submissions` 错误数 | Vercel Logs | 每周 2 次 | 是否有 `400 / 422 / 502 / 503` 集中出现 | 有异常峰值：排查表单、Turnstile、GitHub API |
| 系统 | 异常流量 / 缓存误伤 | Cloudflare | 每周 1 次 | 是否有明显 bot 或缓存配置问题 | 投稿异常时优先查 Cloudflare 规则 |
| 商业 | `ad_click` 事件数 | GA4 | 每周 1 次 | 赞助位是否有人点击 | 有点击再考虑推进正式广告售卖 |

## 每周重点

| 周次 | 日期 | 主要目标 | 重点观察 |
|---|---|---|---|
| 第 1 周 | `2026-06-01` 到 `2026-06-07` | 技术稳定 | 主域归一、收录开始、投稿链路无报错 |
| 第 2 周 | `2026-06-08` 到 `2026-06-14` | 看首批搜索信号 | 哪些专题 / 分类页先有曝光 |
| 第 3 周 | `2026-06-15` 到 `2026-06-21` | 判断内容方向 | 哪类关键词、哪个页面类型更容易拿到展示 |
| 第 4 周 | `2026-06-22` 到 `2026-06-28` | 准备下一轮迭代 | 决定先补内容、补模板，还是补投稿运营 |

## 每周简报模板

每周只要输出一份简报，至少覆盖以下内容：

- 本周收录页数是多少，较上周增减多少
- 本周曝光最高的 5 个页面或查询词是什么
- 本周专题页里哪 2 篇最有潜力
- 本周新增投稿多少，合格多少
- 本周是否有提交接口报错或异常流量
- 下周只做哪 3 件事

## 当前阶段的判断标准

- 2 周内看到 Search Console 开始有曝光，就是正常起步
- 4 周内如果仍几乎没有曝光，优先怀疑内容量不足和关键词覆盖不足，不要先怀疑技术
- 只要开始出现“某几篇专题先冒头”，下一轮就围绕这些主题做扩写，不要平均用力

## 当前建议的观察顺序

1. 先看 Search Console 是否开始收录和曝光
2. 再看 GA4 是否有稳定访问和有效 landing pages
3. 再看投稿是否开始出现真实需求
4. 最后再决定是否推进广告位商业化
